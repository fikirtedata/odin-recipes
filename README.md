# odin-recipes

## About This Project
Welcome to my first project for **The Odin Project** foundations course! This project demonstrates my ability to use basic HTML to structure a website from scratch, organize project files, and navigate the web development workflow.

## Skills Demonstrated
Once this project is fully completed, I will have demonstrated proficiency in:
* **Basic HTML Structure:** Using proper document declarations, headings, paragraphs, lists, and links.
* **Git & Version Control:** Managing a local repository, staging changes, committing snapshots, and pushing code to GitHub.
* **Command Line Workflow:** Using terminal commands (`cd`, `mkdir`, `touch`) to navigate and manage project directories.
* **File Management:** Structuring web assets and linking multiple HTML pages together cleanly.
